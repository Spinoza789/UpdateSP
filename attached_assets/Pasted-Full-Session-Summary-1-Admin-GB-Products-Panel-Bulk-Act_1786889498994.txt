4 — TG Log: Recipient Username Fix
Admin → Tg Log

The log was showing raw numeric Telegram chat IDs (e.g. @6606206793) instead of usernames for messages sent via broadcasts and automated nudges.

Root cause: those call paths called sendTelegramMessage without a logCtx.recipientUsername, so the log stored null and the UI fell back to recipientChatId
Fix: in sendTelegramMessageFull (the single central send/log function), when recipientUsername is absent from the log context, a DB lookup by telegramChatId now resolves the account's username before the log row is written — covers all future messages from every call path with no changes needed at each call site
Files changed: telegram.ts
