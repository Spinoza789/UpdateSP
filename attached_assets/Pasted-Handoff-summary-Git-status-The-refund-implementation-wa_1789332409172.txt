Features implemented
Group Buy refunds
Customers can request refunds for eligible Group Buy orders.

Supported refund methods:

Account credit

Uses the exact persisted order grandTotal
Amount is server-authoritative
Adds a credit transaction atomically
Retry-safe and idempotent
Crypto refund

Uses external USDC or USDT transfer
Ethereum ERC-20 only
Admin or owning organiser manually sends the transfer
Processor submits the TXID
Server verifies:
Ethereum transaction
Token contract
Recipient wallet
Exact token amount
Receipt status
Confirmation count
The system never sends crypto automatically
Private keys are never handled by the app
Refund statuses:

requested
verifying
verification_failed
completed
Active statuses are:

requested
verifying
verification_failed
Active refunds block sensitive order mutations, including:

Order edits

Relevant organiser and reshipper mutations
