6. Multi-country reshipper assignment
Schema: Added countries JSONB column to gb_reshippers table (startup migration)
Admin UI: Replaced the single country dropdown in the "Assign Reshipper" form with a full multi-country picker:
🇪🇺 Add all EU button (one click adds all 27 EU member states)
Remove EU button when EU countries are present
Individual country picker + Add button for one-offs
Country chips with ✕ to remove individually (EU = blue, others = grey)

Order routing: Updated all 4 spots in admin.ts that match orders to reshippers — the system now expands the full countries array so an order from any covered country routes correctly to the reshipper
7. UK / GB country code alias
"UK" and "GB" are now treated as the same country everywhere in the system
Fixed in country-utils.ts via a CODE_ALIASES map and an expandCountryAliases() helper — one change that propagates to all callers:
Join gate: a user with account.country = "UK" can now join a GB that allows "GB"
allowedCountries / excludedCountries checks: both codes match
Reshipper routing: the in-memory reshipper map now stores entries for both gbId::GB and gbId::UK, and shippingCountry is normalised before lookup — so orders stored with either code route to the correct reshipper
