# How to Request a Group Buy Refund

These steps apply to eligible, confirmed Group Buy orders in the Salt & Peps customer portal.

## 1. Open the order

1. Sign in to the customer portal.
2. Open **My Orders**.
3. Select the confirmed Group Buy order you want refunded.
4. On the order details page, find **Need a refund?** and select **I want a refund**.

The refund option only appears when the order is eligible and refunds are enabled for that Group Buy.

## 2. Choose a refund method

### Account credits

1. Select **Refund to account credits**.
2. Review the displayed refund amount.
3. Select **Submit refund request**.

The request is reviewed and manually processed. Submission does not mean the credit has been applied yet.

### Crypto

1. Select **Refund in crypto**.
2. Choose the available asset, such as **USDC** or **USDT**.
3. Confirm the displayed network, **Ethereum ERC-20**.
4. Enter the destination wallet address.
5. Check the address carefully. Completed on-chain transfers cannot be reversed.
6. Review the amount and select **Submit refund request**.

Crypto refunds are sent externally by the processor and then verified. Only use a wallet that supports the selected asset and network.

## 3. Check the refund status

Return to the order details page to monitor the request:

- **Refund request submitted**: the request was received and is waiting for review.
- **Refund is being verified**: processing or verification is underway.
- **Refund verification failed**: an address, network, or verification problem needs attention. Follow the message shown on the order.
- **Refund completed**: processing finished. Crypto refunds may still take time to appear while blockchain confirmations arrive.

You can return to the order at any time to check the current status.
