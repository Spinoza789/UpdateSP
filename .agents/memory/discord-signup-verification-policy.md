---
name: Discord signup verification policy
description: Approved identity-verification policy for first-time Discord account creation.
---

For first-time Discord accounts, successful Discord OAuth counts as identity verification instead of email verification and CAPTCHA. Any active signup invite-code requirement still applies.

**Why:** The user explicitly chose “Treat Discord OAuth as verification” when asked how new Discord signups should satisfy the existing checks.

**How to apply:** Preserve this policy when changing Discord onboarding or signup gates; do not silently restore email/CAPTCHA requirements or bypass required invites.
