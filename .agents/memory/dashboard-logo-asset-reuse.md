---
name: Dashboard logo asset reuse
description: Records the required approach for reproducing the Salt&Peps dashboard brand lockup elsewhere.
---

When a screen should use the dashboard logo and icon, reuse the dashboard’s exact dual-part lockup: the dark icon rail with the existing `SaltPepsMark`, plus the existing horizontal `/brand` wordmark SVG on its light panel. Do not approximate the logo with HTML text, stacked words, or newly chosen colors.

**Why:** Recreated text lockups repeatedly drifted from the supplied dashboard reference and were explicitly rejected. The user expects asset-level identity, not a visually similar interpretation.

**How to apply:** Inspect the current dashboard brand implementation and copy its asset references, dimensions, colors, and rail treatment. Keep unrelated controls, such as sidebar collapse, outside the wordmark area.
