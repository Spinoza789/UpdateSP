---
name: Wholesale page updates
description: Audience and ownership of general wholesale announcements.
---

Wholesale image-and-note updates are Admin-managed announcements for everyone on the main wholesale order page, not messages limited to one shared order.

**Why:** The user explicitly chose global wholesale updates for price changes, changes and general news.

**How to apply:** Keep general announcements separate from shared-order member messages and from order/payment records.

Wholesale announcements can be marked as read individually by each member; reading must not hide the announcement for other members.

**Why:** The user requested a read button that makes the update go away after reading.

**How to apply:** Save read status to the account, not the browser. Treat a changed announcement as unread again so members do not miss revised information.
