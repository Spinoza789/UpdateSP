---
name: Group buys sharing a vendor
description: Organisers may create separate group buys using a vendor already used by another active group.
---

Allow multiple group buys for the same vendor/manufacturer, including those run by different organisers.

**Why:** The user explicitly approved allowing multiple group buys rather than retaining the site-wide vendor restriction.

**How to apply:** Do not reintroduce vendor exclusivity during creation or activation. Keep organiser access, ownership and public-listing approval checks independent of vendor choice.
