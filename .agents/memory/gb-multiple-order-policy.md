name: Group-buy multiple-order review
description: Why organisers need repeated-order highlighting and the approved scope.
---

Highlight potential repeated orders for review rather than automatically deleting, merging or deducting them.

**Why:** The user reports noticing multiple orders for one person every time they run a group buy, which disrupts their numbers if missed. They approved highlighting in both organiser and Admin GB order lists.

**How to apply:** Keep legitimate additions distinguishable from separate orders and retain existing financial records unless the user explicitly asks for a reconciliation action.
